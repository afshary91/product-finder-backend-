# بک‌اند اپ تطبیق درخواست و عرضه (با احراز هویت پیامکی)

این سرور کارهای زیر رو انجام می‌ده:
- ارسال کد ۴ رقمی به شماره موبایل (از طریق کاوه‌نگار)
- تایید کد و صدور توکن ورود
- نگهداری درخواست‌ها، آگهی‌ها و پاسخ‌های فروشگاه‌ها (به‌جای گوشی، حالا روی سرور مشترک ذخیره می‌شن)

## قدم ۱: ساخت حساب کاوه‌نگار و گرفتن کد OTP

1. برو به سایت [kavenegar.com](https://kavenegar.com) و ثبت‌نام کن (نیاز به شماره موبایل و کد ملی داره)
2. از پنل، بخش **API Key** رو پیدا کن و کلیدش رو کپی کن
3. برو به بخش **Verify Lookup / قالب‌های پیامکی** و یک قالب OTP بساز. معمولاً یه چیزی شبیه این می‌نویسی:
   `کد تایید شما: %token%`
4. اسم این قالب رو یادداشت کن (مثلاً `verify`)
5. حتماً باید حساب رو شارژ کنی (هر پیامک هزینه داره، معمولاً چند تومان)

## قدم ۲: تنظیم فایل .env

فایل `.env.example` رو کپی کن و اسمش رو بذار `.env`، بعد مقادیر رو پر کن:

```
KAVENEGAR_API_KEY=کلیدی که از کاوه‌نگار گرفتی
KAVENEGAR_TEMPLATE=verify
JWT_SECRET=یک متن طولانی و تصادفی و محرمانه
```

برای ساخت JWT_SECRET می‌تونی از سایت [random.org](https://www.random.org/strings/) یه رشته تصادفی بگیری، یا هر متن طولانی و پیچیده بنویسی.

## قدم ۳: تست روی سیستم خودت (قبل از آپلود روی سرور)

```
npm install
npm start
```

اگه پیام «سرور روی پورت 3000 اجرا شد» رو دیدی، یعنی درست کار می‌کنه. می‌تونی با Postman یا حتی مرورگر آدرس `http://localhost:3000` رو باز کنی و پیام «سرور فعاله ✅» رو ببینی.

## قدم ۴: آپلود روی لیارا (Liara)

لیارا یه سرویس ایرانیه که مخصوص همچین کارهاییه و برای شروع ساده‌ست:

1. برو به [liara.ir](https://liara.ir) و ثبت‌نام کن
2. از پنل، گزینه **ساخت اپ جدید** رو بزن و پلتفرم رو **Node.js** انتخاب کن
3. نصب CLI لیارا روی سیستمت (طبق مستندات خودشون، با یک خط دستور نصب می‌شه)
4. داخل پوشه پروژه، با دستور `liara login` وارد حسابت شو
5. با دستور `liara deploy` پروژه رو آپلود کن (CLI به‌صورت خودکار سوال می‌پرسه که کدوم اپ رو دیپلوی کنی)
6. از پنل لیارا، بخش **متغیرهای محیطی (Environment Variables)** رو باز کن و همون مقادیر فایل `.env` رو اونجا وارد کن (KAVENEGAR_API_KEY، KAVENEGAR_TEMPLATE، JWT_SECRET)
7. بعد از دیپلوی موفق، یک آدرس (URL) بهت می‌ده، مثلاً `https://my-app.liara.run` - این آدرس رو نگه دار، توی اپ موبایل بهش نیاز داری

اگه توی مرحله دیپلوی به مشکلی خوردی، مستندات فارسی لیارا (docs.liara.ir) رو ببین یا از پشتیبانی چتی خودشون کمک بگیر - معمولاً برای شروع خیلی سریع جواب می‌دن.

## نکته مهم درباره هزینه‌ها
- **کاوه‌نگار**: هر پیامک OTP هزینه داره (چیزی حدود چند صد تومان به ازای هر پیامک، بسته به تعرفه لحظه‌ای)
- **لیارا**: پلن‌های ماهانه داره، ارزون‌ترین پلن برای این حجم کار کافیه

## قدم بعدی
بعد از اینکه سرور بالا اومد و آدرسش رو گرفتی، باید اون آدرس رو داخل اپ موبایل (در فایل api.js) جایگزین کنی. این کار رو در پوشه اپ موبایل توضیح دادم.
